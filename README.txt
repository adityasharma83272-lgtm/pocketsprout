POCKETSPROUT — FINAL STARTER RELEASE

Files:
- index.html: landing page + interactive app
- manifest.webmanifest: install metadata
- sw.js: offline cache/service worker
- icon.svg: app icon

Deploy:
1. Extract this ZIP.
2. Upload all four app files (and README if desired) together to Netlify Drop.
3. Open the deployed HTTPS URL in Chrome.
4. Use Chrome menu > Install app / Add to Home screen.
5. If an older version is cached, clear the site's storage/cache and reload.

Notes:
- Data is stored locally in the browser using localStorage. Use Export my data for a backup.
- This is a learning/demo app. Paper portfolio prices are illustrative, not live market prices.
- No bank connection, real-money transactions, or investment advice.
- The service worker needs HTTPS (Netlify provides HTTPS).
